## Featured Projects

### 1. [Folder.AI](https://github.com/abhikmahajan/folder-ai) — AI-Powered Productivity Workspace

A full-stack application that brings AI-powered utilities into one place, including text generation, image tools, and résumé review.

- Built a React client and an Express API server.
- Integrated Clerk for authentication and protected user workflows.
- Connected AI services for content generation and image-related tools.
- Used Neon PostgreSQL for application data and Cloudinary for media handling.

**Tech:** React · Vite · Tailwind CSS · Node.js · Express · PostgreSQL (Neon) · Clerk · OpenAI SDK · Cloudinary

### 2. [ZenAthlete](https://github.com/abhikmahajan/ZenAthlete) — AI Fitness & Wellness Platform

An AI-powered fitness platform designed to help users plan workouts, manage nutrition, track progress, and connect with coaches.

- Generates personalised workout plans and nutrition guidance using Google Gemini.
- Includes workout tracking, fitness statistics, and pre-built workout programmes.
- Supports coach messaging and an admin support dashboard.
- Uses Clerk authentication and Supabase for database and real-time functionality.

**Tech:** React · Vite · Tailwind CSS · Node.js · Express · Supabase · PostgreSQL · Google Gemini · Clerk

### 3. [Job Board App](https://github.com/abhikmahajan/job-board-app) — Role-Based Job Portal

A full-stack job board connecting candidates and recruiters through separate role-based workflows.

- Candidates can discover, search, filter, and apply for jobs.
- Recruiters can create, update, and delete job listings and review applicants.
- Implemented JWT-based authentication and password hashing with bcrypt.

**Tech:** React · JavaScript · Tailwind CSS · Node.js · Express · MongoDB · Mongoose · JWT · bcrypt
